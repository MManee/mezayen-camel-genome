# Data Access

This repository contains computational workflows and reproducibility
documentation only. Large sequencing and genome data files are not stored
in the GitHub repository.

## Genome assembly

Species:

    Camelus dromedarius

NCBI Assembly accession:

    GCA_037784275.1

The assembly corresponding to this accession should be obtained directly
from NCBI.

## Annotation and supporting files

The genome annotation, protein and CDS sequences, functional-annotation
results, quality-control outputs, and associated supporting files are
available through Figshare:

    https://doi.org/10.6084/m9.figshare.33193326

The current Figshare record contains the genome resource and its revised
protein-coding annotation.

## Repository data policy

The following are intentionally not duplicated in this repository:

- Raw sequencing reads
- Genome FASTA files
- Large alignment files
- Large intermediate assembly files
- Large annotation-result tables already deposited in Figshare

The GitHub repository instead provides:

- Command-line workflows
- Configuration files
- Software-version information
- Reproducibility documentation
- Parameter settings used in the analyses

## Raw sequencing data

Raw-read accession identifiers should be cited here only after they have
been verified against the associated public repository records.
